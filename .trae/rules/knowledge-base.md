# 任务开始前先读 .trae 知识库

本项目使用 `.trae` 知识库记录项目结构、设计、思考与任务。每次任务开始前,先阅读:

- `.trae/HANDOFF.md`:当前状态、先读入口与下一步;多阶段任务以此作为交接索引。
- `.trae/documents/HANDOFF_PROTOCOL.md`:所有 AI 工具通用的信息维护协议;若当前任务跨多个步骤/会话,按此持续更新 handoff。
- `.trae/documents/STRUCTURE.md`:项目结构与模块职责(涉及结构改动后须同步更新)
- `.trae/documents/DESIGN.md`:项目目标与设计理念
- `.trae/documents/NOTES.md`:历史思考、问题与决策记录
- `.trae/documents/RULES.md`:本项目的 agent 约束规则,必须遵守
- `.trae/todo/TODO.md`:任务清单,先完成 `( )` 未完成项,完成后勾选为 `(X)`

对项目事实不确定时,优先查阅 `.trae` 下文档,不凭猜测作答。
