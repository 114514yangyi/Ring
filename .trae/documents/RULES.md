# RULES — 对 agent 的约束规则

本文件是项目内所有 agent(包括自动编码与文档任务)必须遵守的约束。开始任何任务前先阅读本文件。

1. **任务开始前**:先阅读 `.trae/documents/` 下的 `STRUCTURE.md`、`DESIGN.md`、`NOTES.md`、`RULES.md` 与 `.trae/todo/TODO.md`,明确项目结构与待办,再开始任何工作。
2. **动手前**:对照 `STRUCTURE.md` 确认相关模块的职责与位置;若改动会影响项目结构或模块划分,完成后同步更新 `STRUCTURE.md`。
3. **过程记录**:遇到问题、做出设计决策或产生值得留存的思考时,按"日期 + 问题/思考/结论"格式追加到 `.trae/documents/NOTES.md`,不要只留在对话里。
4. **完成时**:在 `.trae/todo/TODO.md` 中将对应条目勾选为 `(X)` 并简要注明改动;新需求由用户添加条目,agent 不得自行添加或删除条目。
5. **参考代码**:与项目无关或作为参考对照的代码文件,一律放入 `.trae/reference/`,不得混入项目源码目录。
6. **一致性**:`.trae` 文档与代码冲突时以实际代码为准,并回头修正文档;对项目的事实不确定时,先查阅 `.trae` 下文档,不凭猜测作答。
