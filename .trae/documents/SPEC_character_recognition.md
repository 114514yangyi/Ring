## 1. 目标与范围

**交付**:把接触段轨迹切分为逐字符样本,训练 26 类(大小写无关)字母分类器,报告 top-1/top-3 与混淆矩阵;数据源同时覆盖 touchpad 真值(GT)与轨迹重建模型输出(端到端真实场景)。单词(连笔/断笔、3000 词表+DTW)为第二阶段。

**非目标**:52 类大小写敏感;词级语言模型/纠错;实时部署。

**成功标准**:
1. GT 轨迹上的字母识别率显著高于重建轨迹,且给出端到端识别率;
2. 给出用户无重叠划分(主)与随机划分(辅)结果、混淆矩阵;
3. 与论文 88.7%(Google IME)对照时说明协议差异(数据集、分类器、大小写处理);
4. checkpoint/report/测试/文档齐全。

## 2. 数据事实(已侦察)

- 字母块 action 0/1 共 192 个,每块 26 个标签;89 块小写、89 块大写;`wrong` 标签 55 个需丢弃。
- 清洗样本开头约 3 个字母被裁掉(585/4628 标签在 clean 时间范围外),结尾 8 个;可用字符样本约 3800。
- 每个字符平均对应 1.55 个接触段(多笔画字母 2-3 段),需按相邻标签时间戳区间合并接触段。
- 标签时间戳与 clean 时间轴同历元(µs),映射到帧用 `searchsorted`(裁剪到有效区间);样本 raw 对齐已在 Madgwick 探针验证。
- 单词块 action 2-5 标签为整词(每块约 20 词),无词内字符时间戳。

## 3. 方法设计

- **切分**(`character_dataset.py`):
  - 接触段 = 连续 `mask=1` run(最短 8 帧);
  - 标签 i 的帧区间 `[frame_i, frame_{i+1})` 内、起点落入的接触段归该字符;合并为一个字符(每段内相对首点坐标,拼接成多笔画折线);
  - 丢弃 `wrong`、时间范围外、接触帧数不足的字符。
- **轨迹特征**:按弧长重采样到 64 点 → 平移(首点归零)→ 按 bbox 对角线缩放;GT 与重建同流程。
- **重建轨迹**:用轨迹模型(X3/主模型)对整块预测逐帧位移,按接触段积分(段内起点归零)得到各段预测轨迹,再按同一字符切分规则组装。
- **分类器**(`character_model.py`):小 1D CNN(2→32→64→128,BN+ReLU+池化,全局平均池化,FC 26)。
- **训练**(`train_character_classifier.py`):CE、Adam 1e-3、batch 128;数据源 `gt`/`recon`/`both`(混训时各半);轻量增广(缩放 ±10%、旋转 ±10°、时间扰动);用户无重叠为主、随机划分为辅;按验证准确率选 best。
- **评估**:test 上分别报告 GT/recon 的 top-1、top-3、混淆矩阵;report.json 记录 split、样本数、配置、history。

## 4. 风险与开放问题

| 风险 | 应对 |
| --- | --- |
| 重建轨迹漂移直接拉低端到端识别率 | 混训 + 增广;GT 与 recon 分开报告 |
| 切分把多笔画字母拆错或粘连 | 时间区间分组 + 最短段过滤;报告被丢弃数量 |
| 大小写合并影响与论文对比 | 统一 26 类,说明与论文口径差异 |
| recon 轨迹收益/成本 | 预计算缓存,训练不重复跑轨迹模型 |
