# WritingRing 复现汇报素材：轨迹重建与字符/单词识别

## 0. 项目一句话

从单 IMU 戒指（6 通道：三轴线加速度 + 三轴角速度，200 Hz）出发，复现 WritingRing（He et al., CHI 2025）的指尖书写轨迹重建，并进一步完成轨迹到字母、单词的识别，给出与原论文的量化对比和方法层面的差异分析。

## 1. 数据集与数据语义

- 官方 clean 数据 `clean_data_delete_g`：21 个用户、566 个样本（2 个长度不一致已跳过，564 个可用）；200 Hz 均匀网格；每个样本包含：
  - `*_x.npy`：6 通道 IMU（lin_acc_x/y/z, gyro_x/y/z）
  - `*_board.npy`：触控板真值轨迹（归一化坐标）
  - `*_mask.npy`：接触标志（与 board 非零一致）
  - `*_y.npy`：逐帧位移，实测语义 `y[t] = board[t+1] − board[t]`（帧级相关 0.97，积分后 0.9995）
  - `*_timestamp.npy`：时间轴
- 原始数据 `data/`：12 GB，含逐字符/逐词时间戳标签（`*_timestamp.txt`）与原始 Sensel 触点；clean 版已重采样并裁剪到触控板重叠区间。
- 长度不一致的坏样本 2 个（user_0/0/0、user_7/0/0）已跳过，实际训练/评估用 564 个。

## 2. 任务 1：轨迹重建方法

- 输入：去重力后的 6 通道 IMU；输出：帧级指尖位移 (Δx, Δy)。
- 模型：13 帧滑动窗 → TCN（kernel 3，论文要求 TCN 输出 1×128）→ LSTM(128) 流式 → 预测窗口中点位移（使用 6 帧未来数据，延迟 32.5 ms）。
- 训练：75 s / 15000 帧长片段流式训练；MSE，仅接触帧（mask=1）计入 loss；随机 70/10/20 划分为主口径，另做用户无重叠划分作为严格对照。
- 推理：预测位移仅在接触段内积分，重建 2D 轨迹。
- 评估：论文口径的逐点归一化距离（除以该段 GT 包围盒对角线）+ 无归一化 mm 误差（按 Sensel Morph 240×169.5 mm 假设换算）。
- 论文参考值：归一化误差 0.073、mm 1.64、80% 轨迹误差 < 0.1。

## 3. 任务 1：轨迹重建结果（随机划分，test 113 样本、11748 个接触段）

| 模型 | 归一化误差 | mm 误差 | 逐段均值 <0.1 占比 |
| --- | --- | --- | --- |
| V4 流式（论文口径） | 0.1238 | 5.06 | 55.1% |
| B2 离线双向 | 0.1098 | 4.33 | 60.3% |
| X3 离线双向精调（最佳单模） | 0.1048 | 4.13 | 64.7% |
| Ensemble（v1+x3+b2+v4 位移平均） | 0.1012 | 4.05 | 66.0% |
| 论文（CHI 2025） | 0.073 | 1.64 | 80% |
| 协议噪声底（完美预测官方 y 的可达上限） | 0.0377 | 1.28 | — |

- 路径长度保真：重建/真值路径长度中位比 0.98，相关 r = 0.991（幅度未坍塌）。
- 用户无重叠严格对照（旧架构）：0.2137 / 8.53 mm。
- 结论：全部可复现路线（训练语义、调度、dropout、输入预处理、TCN 拓扑/深度/宽度、LSTM 深度/双向、辅助损失、归一化、全 BPTT、多模型 ensemble）已探索完毕，单模 0.105、集成 0.101 进入平台，距论文约 1.4 倍。

## 4. 任务 1：与论文的差距归因

- TCN 拓扑未公开：论文只给出 kernel=3、输出 1×128；本项目默认 dilated 32/64/128，属公开假设。
- 训练方式：论文为整段 75 s 流式 BPTT；本项目受显存限制用 TBPTT 分块（块长 3000、块间 detach），长程梯度传播受限。
- 输入预处理：论文声称 Madgwick（β=0.041）去重力，但探针对齐实验证明官方 clean acc 与 Madgwick 不吻合（最接近的是 0.5 s 滑动均值去重力，corr 0.90），精确算法未公开。
- 评估口径：官方 `y` 本身含协议噪声（完美预测的逐段误差底就有 0.038 / 1.28 mm），论文 0.073 已接近该噪声底。

## 5. 任务 2a：字母识别

- 数据切分：用原始 `*_timestamp.txt` 的逐字符时间戳把接触段切到字符级；弧长重采样 64 点、去起点归一化。
- 模型：26 类（大小写无关）1D CNN（Conv 2→32→64→128 + 自适应池化 + 全连接）。
- 训练：GT 轨迹与重建轨迹混训；用户无重叠划分（测试用户 16/18/19/20，均未参与分类器训练；user_17 无合格字母样本）。
- 结果（n=708）：
  - 重建轨迹端到端（上界口径：重建前端 x3 为随机划分，约 84% 测试样本其训练时见过）：top1 92.66% / top3 98.87%；在 x3 未见子集上复算 top1 = 88.18%（n=110）
  - GT 轨迹（同模型参考）：top1 94.77% / top3 99.58%
  - 论文（Google IME 解码）：88.7%（协议不同：外部 IME vs 自训 26 类分类器）
- 逐字母 top1（重建轨迹）：A 88.0、B 89.7、C 100、D 89.7、E 100、F 92.9、G 90.6、H 93.3、I 66.7、J 96.8、K 96.8、L 59.1、M 100、N 93.5、O 93.5、P 100、Q 96.3、R 96.9、S 100、T 85.0、U 96.9、V 81.8、W 100、X 91.7、Y 96.0、Z 96.6
- 主要混淆：L↔I、I↔Z、T↔Z、B↔P、D↔Q、X↔Y（形近字母）。

## 6. 任务 2b：单词识别

- 数据切分：整词标签区间分组，分连笔（connected，action 2/3）与断笔（unconnected，action 4/5）；重采样 128 点、deskew、归一化。
- 基线：最近实例匹配（欧氏 / DTW 重排，闭集词表）。
- 主方法：CTC 序列识别 —— CNN(2→64→128) + 双向 2 层 LSTM(128) + 逐帧 27 类 softmax（26 字母 + blank）；贪心解码后用编辑距离对齐词表（词表 = 训练词集，416 词）。
- 结果（用户无重叠，1306 个测试词，GT 与重建各评一次）：
  - 最近实例基线（GT 轨迹，落盘口径 dtw+deskew）：整体闭集 63.2%；connected 44.5% / unconnected 61.0%（全体口径）
  - CTC + 词表对齐（重建子集，上界口径）：65.7%；connected 57.5% / unconnected 74.5%；raw（未对齐）60.6%；GT+重建合并口径 66.2% / raw 61.2%
  - 严格未见子集估计（x3 未见过）：词表对齐 60.0%（n=400）
  - GT-only 训练对照：raw 54.9% / 词表对齐 62.3%
  - 随机划分：raw 68.9% / 词表对齐 81.8%（connected 76.1% / unconnected 87.7%）
  - 论文（Google IME）：开放词表 unconnected 68.2% / connected 53.1%；其 3000 词表下 84.4% / 74.2%
- 分析：词表对齐带来 +5～13 个百分点；连笔（connected）是主要难点；与原论文的差距主要来自解码器（无语言模型、词表 416 vs 3000）。

## 7. 方法对比总表（本项目 vs 论文）

| 环节 | 论文（CHI 2025） | 本项目 | 影响 |
| --- | --- | --- | --- |
| 输入预处理 | 声称 Madgwick β=0.041 去重力 | 直接使用官方 clean 数据；探针证明其非 Madgwick | 无法完全对齐 |
| 轨迹骨干 | TCN（拓扑未公开）+ LSTM(128) | dilated TCN 32/64/128 + LSTM（含 2 层/双向变体） | 拓扑为公开假设 |
| 轨迹训练 | 75 s 整段流式 BPTT、MSE 仅接触帧、500 epochs | TBPTT 分块（3000）、每块一步、cosine/常数调度对比 | 长程梯度受限 |
| 轨迹推理 | 纯流式（延迟 32.5 ms） | 流式 + 离线双向变体（论文之外） | 离线 0.105 优于流式 0.124 |
| 字母识别 | Google IME（含语言模型） | 自训 26 类 1D CNN | 协议不同，不可直接比较 |
| 单词解码 | Google IME + 3000 词表 + 语言模型 | CTC + 416 词表编辑距离对齐 | 缺语言模型，是主要差距来源 |

## 8. 结论与下一步

- 轨迹重建：单模 0.1048、集成 0.1012，距论文 0.073 约 1.4 倍；论文值已接近数据协议噪声底（0.038），进一步逼近需要论文未公开的实现细节。
- 字母识别：重建端到端 top1 92.7%（上界口径；严格未见子集估计 88.2%），GT 输入 94.8%；与论文 IME 88.7% 协议不同，严格口径下同量级。
- 单词识别：重建子集词表对齐 65.7%（上界口径；严格未见子集估计 60.0%，合并口径 66.2%），与论文开放词表 IME（68.2 / 53.1）量级相当；缺口在语言模型与大词表。
- 下一步候选：CTC 词表约束 beam search；多种子 ensemble；实时链路端到端联调（戒指原始帧 → touch detector → 轨迹 → 字符）；等待论文补充材料公开 TCN 细节。
